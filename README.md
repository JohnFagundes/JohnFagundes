# Olá! 👋 Me chamo João Victor Fagundes

### Desenvolvedor Full Stack | Front-end com React e TypeScript

Sou desenvolvedor de software de Aracaju-SE, com experiência no desenvolvimento de aplicações web, interfaces modernas, APIs REST e sistemas de gerenciamento. Atualmente, trabalho na evolução de uma plataforma SaaS, atuando principalmente na arquitetura e no desenvolvimento Front-end com React.js e TypeScript, além de realizar ajustes no Back-end com Node.js.

Minha jornada na programação começou em 2020. Em 2022, iniciei a graduação em Sistemas de Informação pela Descomplica Faculdade Digital e, em 2023, concluí minha formação intensiva em Desenvolvimento de Software Full Stack pela Cubos Academy.

Tenho interesse em arquitetura de software, qualidade de código, performance, experiência do usuário e desenvolvimento de soluções que atendam a necessidades reais de negócio. Também possuo experiência com bancos de dados, integrações de APIs, serviços em nuvem e infraestrutura de servidores.
